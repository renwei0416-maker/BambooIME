# 苍竹输入法 / BambooIME

Android 输入法，源自 **灵韵输入法（LyraIME）**，引擎为 **Rime**，界面沿用 **同文输入法（Trime）** 的键盘体系。

| 层级 | 项目 | 关系 |
| --- | --- | --- |
| 输入法引擎 | [Rime](https://github.com/rime/librime) | 上游 |
| 键盘界面 | [Trime / 同文输入法](https://github.com/osfans/trime)（GPL-3.0） | 上游 |
| Android 宿主 | [LyraIME / 灵韵输入法](https://github.com/Carlson24/LyraIME)（GPL-3.0，基于 Trime 5.5.2） | 直接上游 |
| 本项目 | BambooIME / 苍竹输入法 | LyraIME 的派生版 |

本项目遵循上游许可证 **GPL-3.0**。

## 相对上游（灵韵 5.5.2）的改动

### 品牌与包

| 项目 | 灵韵 | 苍竹 |
| --- | --- | --- |
| 包名 | `com.carlson.lyraime` | `com.bambooime` |
| 显示名 | 灵韵输入法 | 苍竹输入法（BambooIME） |
| 用户目录 | `Documents/LyraIME` | `Documents/BambooIME` |
| 图标 | 默认图标 | 自绘图标（墨绿底 + 楷体「竹」） |

包名不同 → 两者可以同时安装、同时在输入法列表里出现，数据互不干扰。
内部 Kotlin 命名空间仍为 `com.osfans.trime`（沿用上游，不影响使用）。

### 新增功能：苍竹增强

一个独立于 Rime 方案的模块，入口在「设置 → 苍竹增强」，**不修改用户的方案文件**。

1. **回退**：在拼写框输入触发码（默认 `qq/`），删掉最近一次上屏的内容；一次退一笔。自己记账，不读整篇文档。
2. **AI 发送**：
   - 8 套内置提示词模式（默认 / 英文 / 日文 / 润色 / 中文 / 校对 / 扩写 / 回复），可改、可删、可新增；
   - 触发方式二选一：**快捷组合键**（默认 `ctrl+;`）或**双击按键**（默认 `/`）；
   - 模式常驻，再打同一个码退出，打另一个码直接切换；
   - **剪贴板**另有两条独立通道（快捷码 `jt;` 与组合键 `ctrl+alt+;`）；
   - 非编码状态下可只发送「最后一个结束符号之后」的那一句（符号可配置）；
   - 候选字不会随发送一起上屏（可关）；
   - 结果以纯文本上屏，不会被再次解析成触发码。

详细配置见 Release 附件 `BambooIME-1.0.0-config-guide.md`。

### 安全与隐私

- **API Key 加密**：Android Keystore（AES-256-GCM）加密保存，磁盘无明文；随 `bamboo_actions.xml` 一起被排除在系统备份与换机迁移之外。
- **隐私**：仅在用户主动触发时才发送文本；密码输入框不记账、不参与回退；单次发送上限 4000 字符。

## 下载与安装

安装包见 **Releases** 页面。

1. 安装 APK（仅 `arm64-v8a`），首次打开按引导授权；
2. 在系统「语言与输入法」里启用「苍竹输入法」，并设为当前输入法；
3. 导入 Rime 方案包：把方案目录（含 `default.yaml` 与 `*.schema.yaml`）放到 `/sdcard/Documents/BambooIME/`，在「设置 → 方案包」里选中；
4. 需要 AI 时，在「设置 → 苍竹增强」填接口地址、模型、API Key。

> 本应用**不内置任何输入方案**，与上游一致。首次使用必须自行导入方案包。

配套主题包见 Release 附件 `themes.7z`，解压后按其中说明放入用户目录的 `themes/` 下。
