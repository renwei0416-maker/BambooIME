# 苍竹输入法 / BambooIME

Android 中文输入法。

除了引擎与键盘体系自带的能力，这里另外加了：**回退（连续回退）、AI 调用、手写板、拍照识字、重构的符号面板、符号补全、剪贴板增强、外接键盘增强、文曲星、外文学习、语音发AI、外观配置**，以及把常用编辑动作做成主题可绑定的**动作名**。


---

## 功能

### 回退

在拼写框里打触发码（默认 `qq/`）或者键盘退格键“右滑”，删掉**最近一次上屏**的内容，一次退一笔。自己记账，删完按编辑器实际删除的量扣账，不会多删也不会少删。

也可以在主题里把键位绑成动作名 `BambooRevert`，行为完全一致（配套主题里退格的右滑就是它）。

### AI 调用

把光标前的内容、候选的内容、剪贴板的内容丢给大模型处理，结果直接上屏。配套主题里，**回车键上滑就是发送**、**右滑是发送剪贴板**，不用记任何码。
AI模式可以让你有任何问题时，不用切换到别处去查询。跟人聊天时，文字工作者码字时，遇到不懂的问题，直接输入对应问题马上在编辑区得到答案。
切换到英文或者日文模式可以让你无障碍的跟国际友人聊天。还有更多为文字工作者定义的模式，比如润色、校对、扩写等。
同时该模式还可以无限扩展，你可以配置自己的AI触发码，配置对应的提示词。从而让这个模式可以干更多的活。

除了滑动手势，还有两种触发方式：

- **快捷组合键** ctrl+;（默认开，主要给外接键盘）与**双击 /**（默认关），各自独立开关；
- **触发码**：先打模式码进入该模式，再按发送键；模式码见下表。

内置 11 套提示词模式，触发码可改、提示词可改、也可以自己新增：

| 模式 | 触发码 | 模式 | 触发码 | 模式 | 触发码 |
| --- | --- | --- | --- | --- | --- |
| 默认 | `ai;` | 润色 | `rs;` | 校对 | `jd;` |
| 英文翻译 | `eg;` | 中文翻译 | `fy;` | 扩写 | `kx;` |
| 日文翻译 | `jp;` | 回复 | `hf;` | 聊天 | `lt;` |
| 文曲星模式 | `mj;` | 退出模式 | `tc;` | | |

- **模式常驻**：再打同一个码退出，打另一个码直接切换，也可以打退出码 `tc;`从而从任何模式退出；
- **剪贴板**两条独立通道：快捷码 `jt;` 与组合键 `ctrl+alt+;`；
- 非编码状态下可只发送「最后一个结束符号之后」的那一句，结束符号可配置；
- 结果以纯文本上屏，不会再被当成触发码解析；
- 默认接口 `https://api.deepseek.com/v1/chat/completions`，默认模型 `deepseek-flash`，接口与模型都能自己改。

### 语音发AI

按住空格说话，**说完的那一刻，识别出来的文字就直接交给当前 AI 模式处理**——不用再复制、不用再发送。

- **怎么用**：长按空格开始录音（波纹与提示跟原来一样），松手后识别，结果按你选的时机处理：
  - 只在进入了 AI 模式时才发（默认）——没进模式就只上屏，跟以前完全一样；
  - 始终发（没进模式时用默认模式 `ai;` 发）；
  - 从不发（等于关掉这个功能，退化成单纯的语音输入）；
- **顺手纠错**：可以给语音这条通道叠加一段专用提示词（默认开、内容可改），大意是「这段文字是语音识别出来的，先按上下文纠正明显的识别错误，再完成后面的要求」——它叠在你当前模式的提示词前面，不改动任何模式自己的提示词；
- **原文照常进回退账本**：识别出来的文字无论发不发 AI、上不上屏，都能用 `qq/` 退回；
- **设置页**「语音发AI」里可以调：发送时机、是否同时上屏识别原文、是否叠加纠错提示词（可逐字改、可恢复默认）、失败时是否把原文补上屏、超时秒数、太短不发（默认 2 字）、太长截断、要不要显示处理状态；
- **前提**：主题的空格长按要从 `VoiceAssist` 换成新的动作名 `BambooVoiceAi`（配套主题已换好）。用旧主题时录音照旧，只是不会把结果交给 AI。

### 手写板

- 内置 `ochwpro` 中文字迹模型（约 7 MB，MIT 许可），**完全离线**，随安装包一起装好，不需要额外下载；
- 从切换键长按弹窗进入，占住键盘区域；
- 抬笔 0.5 秒自动识别；候选按段累加，可以连写多段再整段上屏；
- 候选带拼音；⌫ 三层语义（清候选 → 清笔迹 → 删编辑器里的字），长按连删；
- 面板带数字 / 中文 / 英文 / 符号四页，数字页可以直接列算式；
- 退格键按**一个字符**删：emoji 这类占两个编码单元的字符一次删干净，不会留下半截乱码方块。

### 拍照识字

- **相机取字**：把文字对准取景框，识别结果进确认卡片；
- **相册取字**：从相册挑一张已有照片，拖动 / 双指缩放 / 双指旋转对准取景框，再识别；
- **两种取景模式**：整段（长条框，读多行）与单字（方框，只认框中央那一个字）；
- **镜头与倍率**：支持双指捏合缩放，按设备镜头切换倍率档；
- **确认卡片**：结果可以先改字、复制到剪贴板，确认后一键上屏；上屏后照样能用 `qq/` 回退；
- 卡片浮在键盘上方，不透明度可调，不会死死挡住聊天软件的输入框。

### 符号面板

建立新的符号模块，规划了一整套符号体系：22 个分类、约 2900 条。

- 覆盖数字、中文、英文、符号、表情、颜文字、数学、序号、箭头、图形、单位、货币、希腊、日文、韩文、拼音声调、音标、上标下标、圈号中文、星座、结构笔画、花体字母；
- 页签可以左右滑动，22 类都放得下；
- 「表情」按笑脸 / 手势 / 人物 / 动物 / 食物 / 旅行 / 活动 / 物品 / 符号 / 旗帜 10 类全收（1900 多个），「颜文字」按 21 类收（490 多条），点页签后面的 ▾ 就能切；
- 每个分类的第一项都是「常用」，放这类里最常打的那些；
- 也能从键盘直接打开：主题里把键位绑成 `BambooSymbol` 进符号页、绑 `BambooNumber` 进数字页；
- **「常用」页**（第一页）：自动记下你从这个面板上屏过的符号，按上屏次数排序、最多留 20 个，短的六个一行、长的独占一行；长按「常用」页签可以清空这份记录（清空后右侧符号列的排序也一起回到默认）；
- **「邮箱」页**：25 个常用邮箱后缀（国内外都有），三列排布，打 `@` 之后一步到位；
- 页签按名字长短自动定宽，一屏能看到七八个分类，不用来回滑。

### 符号补全

打左半边，自动补右半边，光标停在两个符号中间。

- 支持全角与半角两套：`（）` `［］` `｛｝` `《》` `〈〉` `「」` `『』` `【】` `〔〕` `〖〗` `“”` `‘’`，以及半角的 `()` `[]` `{}` `""` `''`；
- 开关都在「设置 → 输入增强」，三个独立开关：总开关（默认关）、「后面已经是右半边时跳过去」（默认开）、「引号也参与配对」（默认开）；
- 组句过程中不插手，交给输入法自己处理；密码框里一律不补；
- 引号本来会被输入法引擎左右交替，这里另给了两枚动作名绕开它，见下面「引号的两枚 token」。

### 剪贴板

新增的能力：

- **按内容类型分页**：全部 / 文本 / 链接 / 电话 / 邮箱 / 地址 / 图片，找东西按类型翻，不用在一条长列表里刨；
- **筛选**：只看收藏、只看本地、只看远程；
- **长按动作**：提取内容（验证码、链接、邮箱、手机号、金额、日期、身份证、单号、地址）、复制文本、复制验证码、分词、删除；
- **提取内容认得地址**：省市区 + 路街门牌、小区 / 大厦 + 门牌、单独的门牌号都能认；被空格或逗号打断的地址会拼回一整段，「我的地址是」「我住在」这类开头会去掉；结果按在原话里出现的先后顺序排列；
- **分词按块切**：切开的块拼起来正好是原文——空白也留成块（显示为 `␣` 和 `↵`），链接、邮箱、电话、带千分位的数字、连着的运算符都各自整块，点选不相邻的几块也不会粘在一起；
- **提取规则可自定义**：设置里一行一条正则，留空就用内置的那十几条（含地址规则）；
- **上屏可回退**：从剪贴板上屏的内容照样能按 `qq/` 退回（图片除外）。

### 外接键盘

接上实体键盘后，输入法会让出屏幕，改在光标附近显示：

- **候选条**跟着光标走，每个候选带 1–9 的序号，直接按数字选；显示 1–6 个都可调，可横排可竖排，候选字与上方编码的字号也能单独调；
- **状态条**显示中/英、CAPS、全角/半角、中文/英文标点，点一下切换；另有齿轮进设置、三角把整条收成只剩中/英。两种形态都能拖动，位置和大小时刻记住；
- 设置里新增一级「外接键盘」，可以逐项决定状态条显示什么、候选条显示几个、字号多大。

### 文曲星

**记得诗名，或只记得其中一句，都能把整首调出来。**

不用去搜、不用切 App：把记得的那几个字打出来，整首诗就摆在候选边上，一键上屏。

| 你打出来的 | 它会给你 |
| --- | --- |
| `静夜思` | 李白《静夜思》全诗 |
| `床前明月光` | 同上——只记得一句也行 |
| `昔人已乘黄鹤去` | 崔颢《黄鹤楼》全诗（连带出处一起列） |
| `明月几时有` | 苏轼《水调歌头·明月几时有》全词 |
| `劝君更尽一杯酒` | 该名句本身 + 出处（这一篇若在词包里，会直接给整首） |

- **三种用法**：常开（边打边查）、触发码直接显示、触发码发送再查；触发码默认 `mj;`，再打一次退出，也可以打 `tc;` 退出；
- **怎么让它查**：常开与「直接显示」模式下，一边打它就一边查，直接就显示在输入候选的上方，无须其它动作；「发送再查」模式下，**回车键上滑**（配套主题）或按发送键才查。查的对象是当前首选候选，没有候选时用光标前那句；
- **发送键与 AI 共用**：`回车键上滑` / 主题动作名 `BambooAiSend` / `Ctrl+;` / `Ctrl+Alt+;`——当前进的是哪个模式就走哪个，不需要分开记；
- **怎么显示**：结果显示在编码行下面一块**独立区域**（和外语学习共用这一块，同时只会显示其中一块），几条命中显示几条（1–6 可设），每条带圆圈编号、条目字数可调（默认 40，最多 100），最后一条后面跟「共 N 组」；
- **怎么上屏**：`,` 上屏第一条；命中 2 条时 `.` 直接上屏第二条；3 条以上时 `.` 按条目轮换，编号跟着条目走，轮一圈回原位；
- **词包**：内置《诗词名句》《楚辞》《唐诗一千首》《宋词一千首》，其余（全唐诗、全宋词、元曲、明诗、清诗、明清词、名句大全）可导入；设置里能看目录、逐个启用、从文件导入。

### 外语学习

**边打字边认词：候选上面那一条，中文后面跟着对应的英文或日文。**

不起眼但很有效——一页候选扫过去，顺手就把词记住了。

| 你打出来的 | 提示区里显示 |
| --- | --- |
| `银行` | 银行  bank |
| `上下文菜单` | 上下文菜单  context menu |
| `一丘之貉` | 一丘之貉  jackals of the same tribe; fig. … |
| `学校`（日语） | 学校(がっこう) |
| `食べる`（日语） | 食(た)べる |

- **两种显示方式**：「始终显示候选项」每个候选占一行，词库里没有的只显示中文（斜体、可调淡）；「只显示命中项」没查到的整条不出现，从当前候选往后最多看 6 个；
- **一门语言一次**：设置里选英语或日语，装多个语言包也只加载选中的那个；
- **英语**：CC-CEDICT，11.5 万词 / 18.7 万义项，含词性、语体标签、量词；**日语**：24.7 万词 / 24.7 万义项，带假名注音；
- **细节可调**：最多几行、每条多少字、义项个数、要不要显示词性／语体／领域标签／量词、字号、未命中行的字号与不透明度、背景不透明度；
- **怎么上屏**：长按候选弹菜单选「上屏外文」，或者用主题动作名 `BambooTip`（当前高亮那条）／`BambooTip1`–`BambooTip6`（第 1–6 行）；配套主题已经把它们绑在数字键 1–6 的下滑上；
- **词库不进安装包**：设置里「下载语言包」或「从文件导入」，放在 `Documents/BambooIME/glossary/`；换机不丢，卸载重装也还在。

### 提示区（文曲星与外语学习共用）

编码行下面那一块就是提示区，两个模块共用这一块的样式，但**同时只会显示其中一个**：

- 一条一行，行与行之间有细分隔线；被截断的那一条末尾有一个朝下的小三角，**点它就展开看全文**；
- 展开后是固定高度、可以上下滑，看完点右上角「收起」回到原样；
- 展开状态下**点正文就是把那条内容上屏**，不用先收起来；
- 展开后继续打字、或候选变了，会自动收起并回到顶部，不会卡在上次滑动的位置。

#### 引号的两枚 token（可绑到任何键）

Rime 引擎的 `punctuator` 里有 `'"' : { pair: [ '“', '”' ] }` 这样的配置，引号会**左右交替**：第一次出左引号，第二次只出右引号。开着「符号补全」时，碰上交替到右边的那一次就只能打出一个孤零零的右引号。这两枚 token 就是为了绕开它：

- `BambooQuote`：提交**真正的左双引号**，由「符号补全」补右半边；
- `BambooQuoteSingle`：提交**真正的左单引号**，同上。

它们**不受「回退与AI」总开关影响**，只跟「符号补全」联动：**「符号补全」和「引号也配对」两个开关都开着**才走上面这条路；任意一个关了，就把原键还给引擎，引号交替照旧。

自带主题里已经绑好：45 键系 `j` 键上滑 = `BambooQuote`，37/45 键系 `/` 键上滑 = `BambooQuoteSingle`。用别人的主题时，把下面这两行加进对应键位就行（token 名不区分大小写）：

```lua
-- 双引号：j 键上滑
key(merge(S.mantle, key { click = "j", swipe_up = "BambooQuote" }))

-- 单引号：/ 键上滑
key(merge(S.slash, key { click = "/", swipe_up = "BambooQuoteSingle" }))
```

不开「符号补全」时，这两枚 token 的表现就跟原来的引号键一模一样，所以可以放心用。

| `t` 键（45 键系布局） | ↓ | `BambooAiOff` | 退出当前 AI 模式，效果等同打一遍 `tc;` |
| 「123」键（计算器图标） | 单击 | `KeyboardNumber` | 切到数字键盘 |
| 「123」键（计算器图标） | 长按 | `BambooSymbol`、`Calculator`、`ThemeReload`、`Deploy` | 弹菜单：打开符号面板／计算器／重载主题／重新部署 |
| `b` 键（45 键系布局） | 长按 | `B`、`ZiTools`、`BaiduSearch` | 弹菜单：打字母 `b`／字统网查字／百度搜索上屏的字 |
| 数字键 `1`–`0`（45 键系布局） | ↑ | `!` `@` `#` `$` `%` `^` `&` `*` `(` `)` | 打出对应的符号 |
| `b` 键（17 键布局） | 单击 | `ZiTools` | 直接打开字统网查字 |
| `j` 键（45 键系布局） | ↑ | `BambooQuote` | 上屏左双引号，开启符号补全时自动补右半边 |
| `/` 键（37/45 键系布局） | ↑ | `BambooQuoteSingle` | 上屏左单引号，同上 |
| 数字键 `1`–`6` | ↓ | `BambooTip1`–`BambooTip6` | 上屏提示区第 1–6 行的外文（外语学习／文曲星） |

`ZiTools` 打开的是字统网 `zi.tools`，`BaiduSearch` 打开的是百度搜索，两者查的都是当前上屏的字。

### 这些动作什么时候能用

| 动作名 | 前提 | 说明 |
| --- | --- | --- |
| `BambooAiSend` | 无 | 随时可按；没有进入任何模式时，按「未进模式也发默认模式」的设置决定是发送还是放行给 App |
| `BambooAiClip` | 无 | 随时可按；没有进入任何模式时用默认模式发送 |
| `BambooAiOff` | 在某个模式里 | 不在模式里时按了不会有反应 |
| `BambooRevert` | 有可回退的记录 | 没有记录时提示「没有可回退内容」 |
| `BambooOcr` | 相机权限 | 首次使用会申请，之后直接打开取景框 |
| `BambooNumber` / `BambooSymbol` | 无 | 打开对应面板，`BambooSymbol` 打开的是符号面板的第一页 |
| `BambooTip` / `BambooTip1`–`6` | 提示区这一行有外文 | 没有外文、或提示块正被另一个模块占用时按了不会有反应 |

### 输入能力

Rime 引擎的全部能力都在：多方案（万象、小鹤双拼等）、用户词库与学习、候选栏样式、以及整套 Trime 主题体系。本应用**不内置任何输入方案**，与上游一致，首次使用需要自己导入方案包。

## 安装

安装包与配套主题都在 **Releases** 页面。

1. 安装 APK（`arm64-v8a`，Android 10 及以上）；
2. 在系统「语言与输入法」里启用「苍竹输入法」并设为当前输入法；
3. 导入方案包：把含 `default.yaml` 与 `*.schema.yaml` 的方案目录放到 `/sdcard/Documents/BambooIME/`，在「设置 → 方案包」里选中；
4. 用 AI 的话，在「设置 → 回退与AI」里填接口地址、模型、API Key（留空即用默认值）；
5. 用外语学习的话，在「设置 → 外语学习」里选语言，再下载语言包或从文件导入（`.bge` 放到 `Documents/BambooIME/glossary/` 也行）。

配套主题 `themes-*.7z` 解压后覆盖到用户目录的 `themes/` 下。

> 2.8.0 起空格长按改走本应用的动作名 `BambooVoiceAi`（为了能把识别结果交给 AI）。**主题要用 2.8.0 配套的版本**；用旧主题时录音仍然正常，只是不会发给 AI。

## 隐私

- **不上传任何内容**：只有你主动触发发送时，才会把当时那段文本发给**你自己配置的**接口；
- **密码框不参与**：密码输入框里不记账、不参与回退、不发送；
- **API Key 加密**：用 Android Keystore（AES-256-GCM）保存，磁盘上没有明文，也排除在系统备份和换机迁移之外；
- **手写与识字**：模型全部在本地推理，不联网、不上传笔迹和照片；
- **外语学习**：词典文件在本地，查词不联网、不记录你打了什么。

## 上游与许可

本项目的输入能力来自这三个上游，按 GPL-3.0 发布，与上游一致：

- [Rime](https://github.com/rime/librime) —— 输入法引擎；
- [同文输入法 Trime](https://github.com/osfans/trime) —— 键盘界面体系；
- [灵韵输入法 LyraIME](https://github.com/Carlson24/LyraIME) —— 本项目的宿主分支。

上面这些之外的功能（回退、AI 发送、手写板、拍照识字、符号面板、符号补全、剪贴板增强、外接键盘、文曲星、外语学习、外观）是本项目自己加的。
