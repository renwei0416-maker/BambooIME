# 苍竹输入法 / BambooIME

Android 输入法，源自 **灵韵输入法（LyraIME）**，引擎为 **Rime**，界面沿用 **同文输入法（Trime）** 的键盘体系。

| 层级 | 项目 | 关系 |
| --- | --- | --- |
| 输入法引擎 | [Rime](https://github.com/rime/librime) | 上游 |
| 键盘界面 | [Trime / 同文输入法](https://github.com/osfans/trime)（GPL-3.0） | 上游 |
| Android 宿主 | [LyraIME / 灵韵输入法](https://github.com/Carlson24/LyraIME)（GPL-3.0，基于 Trime 5.5.2） | 直接上游 |
| 本项目 | BambooIME / 苍竹输入法 | LyraIME 的派生版 |

本项目遵循上游许可证 **GPL-3.0**。

## 相对上游（灵韵 5.5.2）的改动

### 品牌与包

| 项目 | 灵韵 | 苍竹 |
| --- | --- | --- |
| 包名 | `com.carlson.lyraime` | `com.bambooime` |
| 显示名 | 灵韵输入法 | 苍竹输入法（BambooIME） |
| 用户目录 | `Documents/LyraIME` | `Documents/BambooIME` |
| 图标 | 默认图标 | 自绘图标（墨绿底 + 楷体「竹」） |

包名不同 → 两者可以同时安装、同时在输入法列表里出现，数据互不干扰。
内部 Kotlin 命名空间仍为 `com.osfans.trime`（沿用上游，不影响使用）。

### 新增功能：苍竹增强

一个独立于 Rime 方案的模块，入口在「设置 → 苍竹增强」，**不修改用户的方案文件**。

**1. 回退**

在拼写框输入触发码（默认 `qq/`），删掉最近一次上屏的内容，一次退一笔。
自己记账、不读整篇文档；删完按编辑器实际删除量扣账。退格右滑绑定的 `BambooRevert` 与之完全等效。

**2. AI 发送**

- 9 套内置提示词模式：默认 `ai;`、英文 `eg;`、日文 `jp;`、润色 `rs;`、中文 `fy;`、
  校对 `jd;`、扩写 `kx;`、回复 `hf;`、聊天 `lt;`，可改、可删、可新增；
- 触发方式各自独立开关：**快捷组合键**（默认 `ctrl+;`，主要给外接键盘）与**双击按键**（默认 `/`，默认关闭）；
- 模式常驻：再打同一个码退出，打另一个码直接切换，另有退出码 `tc;`；
- **剪贴板**两条独立通道：快捷码 `jt;` 与组合键 `ctrl+alt+;`，各自可关；
- 非编码状态下可只发送「最后一个结束符号之后」的那一句（符号可配置）；
- 候选字不会随发送一起上屏（可关）；结果以纯文本上屏，不会被再次解析成触发码；
- 默认接口 `https://api.deepseek.com/v1/chat/completions`、默认模型 `deepseek-flash`，留空即用默认值。

**3. 手写板**

- 内置 `ochwpro` 中文字迹模型（约 7 MB，MIT，离线、不联网），随 APK 安装；
- 从切换键的长按弹窗进入，占住键盘区域；
- 抬笔 0.5 秒自动识别，候选按段累加，支持连写多段后整段上屏；
- 候选显示拼音；⌫ 三层语义（清候选 / 清笔迹 / 删编辑器字）+ 长按连删；
- 面板四页签（数字 / 中文 / 英文 / 符号）共 96 个符号，数字页可直接列算式；
- 独立一级设置：停顿时长、候选个数、显示拼音、笔宽、跟随主题配色、模型信息。

**4. 主题动作名（token）**

主题键位可直接绑定：

| 动作名 | 作用 |
| --- | --- |
| `BambooRevert` | 回退最近一次上屏 |
| `BambooClear` | 清空整个编辑区（光标前后全删） |
| `BambooDeleteLine` | 删到行首 |
| `BambooDeleteWord` | 删光标前一个词 |
| `BambooAiSend` | 发送（等价 `ctrl+;`） |
| `BambooAiClip` | 发送剪贴板（等价 `ctrl+alt+;`） |
| `BambooAiOff` | 退出当前 AI 模式 |
| `BambooSettings` | 打开「苍竹增强」设置 |
| `Handwriting` | 打开手写板 |

### 安全与隐私

- **API Key 加密**：Android Keystore（AES-256-GCM）加密保存，磁盘无明文；随 `bamboo_actions.xml` 一起被排除在系统备份与换机迁移之外。
- **隐私**：仅在用户主动触发时才发送文本；密码输入框不记账、不参与回退、不发请求；单次发送上限 4000 字符。
- **手写**：纯本地推理，不联网、不上传笔迹。

## 下载与安装

安装包见 **Releases** 页面。

1. 安装 APK（仅 `arm64-v8a`，Android 10 及以上），首次打开按引导授权；
2. 在系统「语言与输入法」里启用「苍竹输入法」，并设为当前输入法；
3. 导入 Rime 方案包：把方案目录（含 `default.yaml` 与 `*.schema.yaml`）放到 `/sdcard/Documents/BambooIME/`，在「设置 → 方案包」里选中；
4. 需要 AI 时，在「设置 → 苍竹增强」填接口地址、模型、API Key（留空即用默认值）。

> 本应用**不内置任何输入方案**，与上游一致。首次使用必须自行导入方案包。
> 手写模型是内置的，不需要额外下载。

配套主题包见 Release 附件 `themes.7z`，解压后按其中说明放入用户目录的 `themes/` 下。

详细配置见 Release 附件 `BambooIME-1.1.0-config-guide.md`；2.0.0 起的功能变化见 `BambooIME-2.0.0-whats-new.md`。
