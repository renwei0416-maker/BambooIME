# 苍竹手写（1.1.0 起）

手写板是苍竹内置的独立窗口，和键盘一样占住输入法区域，**不依赖 Rime 方案、不改方案文件**。

## 怎么进、怎么出

| 动作 | 做法 |
| --- | --- |
| 进入手写 | 长按键盘上的**切换键**，在弹出的列表里点「手写」 |
| 离开手写 | 手写板左下角「返回」，回到原来的键盘 |
| 切走再切回 | 切到别的 App 再回来，**还在手写板**（这是有意的）；换输入框不受影响 |

主题里对应的动作名是 `Handwriting`（`lib/preset_keys.lua` 的 `Handwriting = { text = "Handwriting" }`），
所以任何键位都可以写成 `click = "Handwriting"` 直接进手写板。

## 写与选

- 抬笔后 **500 毫秒**自动识别（可在设置里调）。落笔会让计时重新开始，所以连笔不会被切半。
- 识别成功后笔迹自动清空，可以接着写下一个字。
- 候选按**段**累加：写完一个字出候选，再写一个字，候选叠加成两字、三字……点哪一段就上屏那一段。
- 点候选 = 上屏该项；**空格**上屏当前高亮项；没有候选时清空笔迹。
- ⌫ 三层语义：有候选先清候选 → 再清笔迹 → 最后删编辑器里的字；**长按连续删**。
- 右侧符号列：`，。、？！；：` 等常用标点，**按你的点击频率自动重排**（点过的会浮到最上面），
  上格中文、下格英文，点哪个出哪个。

## 面板（左下角「符号」键）

四个页签：

| 页签 | 内容 |
| --- | --- |
| 数字 | `0`–`9` 与小数点，右侧第 4/5 列是 `+ - × /`、`=`、`(` `)`、`%`、`√`、`^`、`π`、`∞`，能直接列算式 |
| 中文 | 全角标点与常用符号 |
| 英文 | 半角符号 |
| 符号 | 96 个常用符号（数学、单位、编辑、图形、箭头、圈号） |

行高按面板高度自动分配（夹在 30–64dp 之间），符号多的时候可以上下滑。
再点一次「符号」键收起面板（此时按钮变成「收起」）。

## 设置

「设置 → 手写」是独立一级：

| 项 | 说明 |
| --- | --- |
| 停顿时长 | 抬笔后等多久开始识别，默认 500 ms |
| 候选个数 | 候选条最多显示几个字，默认 10 |
| 显示拼音 | 单字候选都标读音；两字候选只在被选中时标，三字及以上不标 |
| 笔宽 | 笔画粗细，默认 4 dp |
| 跟随主题配色 | 开：手写区取当前主题的底色/纸色/字色；关：用内置中性配色。对比度不足时自动翻转纸色 |
| 手写模型 | 内置模型，可查看版本与授权 |

## 模型

- 内置 `ochwpro` 中文字迹识别模型（7.0 MB），随 APK 一起安装，**离线可用、不联网**。
- 字表 7,356 类（汉字 7,185 个，覆盖 GB2312 全部 6,763 字）。
- 模型来源与许可见 APK 内 `assets/handwriting/ochwpro/NOTICE-ochwpro.txt`（MIT）。
- 不带模型的轻量包用 `-PbundleHandwritingModel=false` 构建（功能保留，模型需另行导入）。

## 已知限制

- 一次识别**一个字**（连写多字尚未实现，见 `docs/ROADMAP.md`）。
- 目前是抬笔识别，不是边写边识。
- 生僻字只覆盖常用集合；生僻字扩展在路线图里。
- 手写区不参与 Rime 的候选与方案，纯本地识别。
