# 苍竹增强：回退 + AI 模式（零 Lua 实现）

这是把 [rime-actions](https://github.com/renwei0416-maker/rime-actions) 里真正被用到的两个功能
**原生重写**进 BambooIME 的版本：不加载 Lua、不改方案文件、不需要部署方案。

代码位置：`app/src/main/java/com/osfans/trime/actions/bamboo/`

| 文件 | 作用 |
| --- | --- |
| `BambooActions.kt` | 按键判定、回退执行、AI 请求调度 |
| `RevertLedger.kt` | 上屏账本（最近 50 笔），按实际删除量扣账 |
| `AiClient.kt` | OkHttp 调用 `{base}/chat/completions` |
| `AiPrompts.kt` | 9 套内置提示词与默认快捷码 |
| `BambooPrefs.kt` | 独立 SharedPreferences（`bamboo_actions`），改完立即生效 |
| `ui/main/settings/BambooActionFragment.kt` | 设置页「苍竹增强」 |

## 回退

- 触发码默认 `qq/`（可在设置里改，多个用逗号分隔）。语义与原版 `fire_delete` 一致：
  **只删最近一笔上屏**，删完按编辑器实际删掉的码点数扣账；手按退格会把账本里那一笔缩短。
- 一次最多删「最多删除字符数」（默认 500）。
- 删除优先用 `InputConnection.deleteSurroundingTextInCodePoints`（emoji/代理对按 1 个字符算），
  编辑器不支持时退回 `deleteSurroundingText`，并在 `finally` 里结束批量编辑。
- 账本是**启发式**的：你在别处手动改动文本、或用别的输入法删过字，账本会和屏幕不一致，
  这时可能删不准——与 Windows 版一致的已知限制。
- 密码框不记账、换 App/换输入框清账本。

## AI 模式

### 进入 / 退出 / 切换

| 动作 | 做法 |
| --- | --- |
| 进入某个模式 | 打它的快捷码（默认：`ai;` `eg;` `jp;` `rs;` `fy;` `jd;` `kx;` `hf;` `lt;`） |
| 切换模式 | 在 AI 模式下再打另一个模式的快捷码，直接切过去 |
| 退出 | 再打一次**进入时的那个码**，或打退出码（默认 `tc;`，可设置、可留空） |

九个内置模式：默认 `ai;`、英文翻译 `eg;`、日文翻译 `jp;`、润色 `rs;`、中文翻译 `fy;`、
校对 `jd;`、扩写 `kx;`、回复 `hf;`、聊天 `lt;`（可逐条改码、改提示词，也可以自己新增）。

进入后模式**一直保持**（跨空格、跨段落、换 App 都保持），直到显式退出。

### 发送

| 方式 | 做法 | 开关 |
| --- | --- | --- |
| 发送拼写 / 上次上屏 | AI 模式下**双击**发送键（默认 `/`，双击间隔默认 1000ms） | 「双击发送键发送」 |
| 发送拼写 / 上次上屏 | 按快捷组合键（默认 `ctrl+;`，主要给外接键盘） | 「快捷组合键发送」 |
| 发送剪贴板 | AI 模式下按一次剪贴板码（默认 `jt;`，可设置） | 「剪贴板：快捷码生效」 |
| 发送剪贴板 | 按剪贴板组合键（默认 `ctrl+alt+;`） | 「剪贴板：快捷组合键生效」 |
| 任意模式动作 | 主题键位绑动作名，如 `swipe_up = "BambooAiSend"` | 无（常驻，不受开关影响） |

> 两个 AI 发送开关**互相独立**，可以都关掉；都关掉后只剩动作名和快捷码可用。

- 「发送内容」三选一：有拼写用拼写、只用拼写、只用上次上屏（默认第一个）。
  拼写取的是 Rime 的 `commit_text_preview`（**会提交成什么**，是汉字而不是编码）。
- 「发送后丢弃拼写候选」默认开：候选**不会上屏**，只上屏 AI 的结果。
- AI 结果作为纯文本上屏，记入账本，所以可以再用 `qq/` 回退掉。
- 请求期间切换了编辑器 → 结果丢弃，不会串到别的输入框。
- 密码框不会发出任何请求。

## 三种触发方式的区别

同一个「AI 发送」可以从三个地方进来，彼此独立：

1. **动作名（键位绑定）**：主题里写 `swipe_up = "BambooAiSend"`，按下即执行。
   主题的回车键用的就是这条，**不受下面「触发方式」设置影响**。
2. **快捷组合键**：设置里配的 `ctrl+;`（默认），按下真实组合键触发；
   主题里写 `send: "Control+semicolon"` 的键位也走这条。
   主要给**外接键盘**用。
3. **双击按键**：设置里把触发方式切成「双击按键」后，双击 `/`（默认）触发。

1 和 2/3 的区别只有入口：命中后都进同一个 `aiSend()`，模式判定、剪贴板取值、上屏逻辑一致。

> 如果某天回车上滑突然没反应，先看是不是把主题里那行改回了 `send: "Control+semicolon"`
> ——那是第 2 条路，只有组合键设置对得上才会触发。

## 已知限制

- 双引号/浮层预览未实现：`结果先预览再上屏` 目前只提示后直接上屏。
- API Key 明文存在 `bamboo_actions` 偏好里，尚未接 Keystore 加密。
- 触发码在**拼写框为空**时不生效（避免误吞正常打字）。

## 新增：非编码时的「最后一句」

AI 模式下，如果拼写框是空的（不是在打拼音），按发送键时按**结束符号**切句：

- 「非编码时只发结束符号之后」默认**开**：取光标前文本，找到最后一个结束符号（默认 `。？！!?`），
  只把**它之后**的那段发出去 —— 中英混排都能断。
- 关掉则退化为「只发上一次上屏的整段」。
- 结束符号可在设置里改（比如只想按中文句号断，就填 `。`）。
- 一次最多取 4000 字符，防止把整篇文章发出去。

切句规则（`lastSentenceSegment`）：

1. 先去掉结尾的**空格/换行**，但**保留**结尾的标点 —— `我想去公园？` 发出去的是 `我想去公园？`。
2. 跳过结尾连续的结束符号，找到最后一个真正的文字字符。
3. 从那个文字字符往前找最近的结束符号，它之后到结尾（含结尾标点）就是这一段。
4. 结尾只有符号、没有文字（`。。？`）时，退回「上一次上屏」，再没有就提示无内容。

例子：

| 光标前 | 发送 |
| --- | --- |
| `你好。今天几号？` | `今天几号？` |
| `我想去公园？` | `我想去公园？` |
| `第一句。第二句！！` | `第二句！！` |
| `Hello. How are you?` | `How are you?` |
| `abc` | `abc` |

## `jt;` 在任何模式下都能用

- 没进 AI 模式时按 `jt;` → 发给 **default（`ai;`）** 模式；
- 已经进了模式（比如 `eg;`）→ 发给当前模式；
- **不进入、也不退出**任何模式，只发一次。
