# 苍竹输入法 2.0.0

## 新增：拍照识字

- **相机取字**：把文字对准取景框，识别结果进入确认卡片。
- **相册取字**：从相册选一张已有照片，拖动 / 双指缩放 / 双指旋转把它对准取景框，再识别。
- **两种取景模式**：整段（长条框，读多行文字）与单字（方框，只认框中央那一个字）。
- **镜头与倍率**：支持双指捏合缩放，以及按设备镜头切换倍率档。
- **确认卡片**：识字结果可以先改字，也可以复制到剪贴板；确认后一键上屏，上屏后仍可用 `qq/` 回退。

## 新增：确认卡片可调透明度

卡片浮在键盘上方，不透明度可调，避免挡住聊天软件的输入框。

## 配套主题更新

键盘切换弹窗的条目改为图标（中 / 英 / 鹤 / 手写 / 拍），并保留七、18、T9 的文字标识。

---

## 安装

1. 安装 `BambooIME-2.0.0-release-arm64-v8a.apk`；
2. 在系统「语言与输入法」里启用「苍竹输入法」并切到它；
3. 首次使用需要导入一个 Rime 方案（万象、小鹤等均可）；
4. 主题：把 `themes-2.0.0.7z` 解压后覆盖到手机的 `Documents/BambooIME/themes`（或按你原有的主题安装方式替换）。

## 附件

- `BambooIME-2.0.0-release-arm64-v8a.apk` —— 输入法安装包（arm64-v8a）
- `themes-2.0.0.7z` —— 配套主题
- `BambooIME-2.0.0-whats-new.md` —— 本说明

## 已知限制

- 拍照识字一次识别一屏文字；单字模式框内只取一个字。
- 相册识字的旋转、缩放、位移需要自己对准，程序不会自动摆正照片。
- 手写板一次写一个字，抬笔后才识别。
